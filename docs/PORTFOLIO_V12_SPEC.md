# Turini 포트폴리오 v12 활성 규칙

기준 문서: `turini-portfolio-v11/docs/포트폴리오_재건축_v12_최종.md` (노션 「포트폴리오 재건축」 v12 · 2026-10-03)
구현 버전: `5.1.0-portfolio-v12` — `app/portfolio-rules.ts` (5.0.0 → 5.1.0 변경은 맨 아래)
상수: `app/portfolio-rules.constants.ts` — **손으로 고치지 않는다.** 파이썬 레포에서 `python scripts/export_web_constants.py` 로 `rules/portfolio_rules_v12.json` 에서 생성한다. Σ·R 을 갱신(분기 1회, 일간 자료 교체)하면 다시 생성해 커밋한다.

이 문서는 앱에 실제 반영된 규칙의 짧은 기준표다. 근거·출처·결정 이유는 기준 문서 §9·§10 에 있다.

## 출력 — 판정 3축 + 강점 3축 + 추천

종합점수는 없다. 위험등급 · 성향 적합 · 기간 적합을 각각 따로 판정하고, 강점은 성향 적합 · 자산 간 분산효과 · 기간 적합 중 통과한 축만 0~3개 보여준다. 화면의 등급은 서비스 변동성 등급이며 공식 상품등급이 아니다.

| 출력 | 정의 |
|---|---|
| `riskScore` | σ_p = √(wᵀΣw), 연환산 % |
| `riskVar` | 역사적 VaR₉₇.₅ = −quantile(R·w, 0.025) × √P × 100. R = 동결된 수익률 행렬(기간 × 6) |
| `riskGrade` · `riskGradeName` | VaR 밴드 6 ≤1% · 5 ≤10 · 4 ≤20 · 3 ≤30 · 2 ≤50 · 1 >50 — **현행 펀드 위험등급과 같은 밴드·3년·산출법**. 이름 매우낮은위험 · 낮은위험 · 보통위험 · 다소높은위험 · 높은위험 · 매우높은위험 |
| `riskGradeSentence` | `연간 손실 위험(VaR) X% 이하 구간이에요` (1등급은 `50% 초과 구간`). VaR 는 이 문형으로만 말하고 실제 손실 한도로 설명하지 않는다 |
| `downside6m` | 6개월 하방 참고치 = expm1(−1.645·σ·√0.5). 화면 문형 `모형상 6개월 후 하방 참고치는 −X%예요` + "보유기간 중 최대손실이 아니에요" |
| `typeFitLabel` | 성향 범위 [L, U] (인접 중심의 중간값, 안정형 하한 0, 공격형 상한 = ETF 100% σ) 안이면 `성향과 잘 맞아요`, 밖이면 `성향보다 조금·많이 공격적·안정적이에요` |
| `distanceToRange` | 성향 범위까지 남은 %p (범위 안이면 0). 화면 `성향 범위까지 X%p 남았어요` |
| `horizonFitLabel` | **상한 조건** σ_p ≤ cap 이면 `투자기간 기준 안이에요`, 넘으면 `기간에 비해 위험이 조금·많이 커요`. 미달 문구 없음 |
| `recommendationStatus` | `hold` / `recommended` / `horizon_capped` / `no_feasible_target` |
| `nearTarget` · `baseTarget` | 가까운 목표 · 성향 기준 목표의 σ·VaR·등급·하방 + `horizonFitLabel`. 화면은 현재 → 가까운 목표 → 기준 목표를 나란히 보여 준다 |
| `rebalancingActions` | 가까운 목표 − 현재, |delta| ≥ 5%p. **|delta| 내림차순 → 자산군 σ 내림차순 → 고정 자산군 순서**. 5%p 미만은 `residualItems` |
| `strengthAxes` | `type_fit` · `diversification`(섞어서 등급 한 단계 이상 하락) · `horizon_fit`, 이 순서. 문장은 기준 문서 §3-7 고정 문장, 분산 문장의 비교 등급은 `diversificationBaseGrade`(Σw·VaRᵢ 의 등급) |
| `unlockTags` | 가까운 목표 또는 기준 목표에 새로 나오는 자산군의 개념 태그 (가까운 목표 쪽 먼저, `hold` 포함, `no_feasible_target` 이면 빈 배열) |

## 추천

목표 범위 I = 성향 범위 ∩ [0, cap]. 성향 하한 ≥ cap(충돌: 중립형·1년 미만, 중립형·1~3년, 공격형·1년 미만, 공격형·1~3년, 공격형·3~10년)이면 그 기간의 밴드를 목표로 쓰고 `horizon_capped` 로 고지한다. 보유 자산군만으로, 필요하면 현금 → 채권 → 주식형 ETF 순으로 최대 1개 추가. 5%p 격자, I 안쪽 10% 우선, L1 최소. 12칸 전부에서 hold 또는 추천이 나온다. `horizon_capped` 인데 현재 σ 가 이미 기간 밴드 안이면 현재 배분을 유지하고 액션을 만들지 않는다. 범위·상한 판정은 원값으로 하되, 상수가 소수 4자리로 동결되므로 경계에 ±0.0005 허용 오차(`EPS`)를 둔다.

## 면책·LLM

화면 하단 면책은 기준 문서 §4 고정 문구(`PORTFOLIO_DISCLAIMER`)만 보여 준다. 데이터 한계 안내(`MODEL_LIMITATION`, 주간 시계열·임시 VaR)는 엔진에 남아 있지만 화면에는 표시하지 않는다. LLM(`route.ts`)은 요약만 쓰고 강점·주의점·조정안은 엔진 값을 그대로 반환한다. 요약의 숫자는 computed 값 · 상수(범위 경계·기간 상한·등급 밴드·기준일) · 현재/가까운 목표/기준 목표 비중 · 자산군 종수만 허용하고, `horizon_capped` 인데 "기간 기준을 우선" 고지가 없으면 대체 문장을 쓴다.
